# PicTro

An interactive, responsive prototype for a Ghana public-transport platform, derived from the supplied project plan and branded as PicTro.

## Run it

Open `index.html` in a browser, or serve this folder locally for the installable PWA experience:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Included flows

- Passenger journey finder, live bus tracking, fares, wallet, payment history, and PicTro Pass.
- Driver/mate operations hub with capacity, demand, collection, and cash recording.
- Management dashboard with demand, revenue, route performance, and staffing signals.
- Responsive desktop/mobile layout and a service worker for basic offline caching.
